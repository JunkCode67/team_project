# 🏆 HackPlatform (Tournament Management System)

Повноцінна MVP-платформа для проведення хакатонів та змагань. Дозволяє організаторам створювати турніри, учасникам — здавати свої проекти, а журі — оцінювати роботи та формувати фінальну таблицю лідерів.

## 🚀 Технологічний стек

* **Frontend:** React, Vite, React Router, CSS Modules
* **Backend:** C#, .NET 8, ASP.NET Core Web API
* **Database:** PostgreSQL, Entity Framework Core
* **Infrastructure:** Docker (через `docker-compose`)

## ✨ Основний функціонал

* **🔐 Авторизація та Ролі:** Безпечна реєстрація та вхід через JWT-токени. Підтримка ролей (Admin, Jury, Participant).
* **⚙️ Адміністративна панель:** Створення нових турнірів та раундів, налаштування лімітів команд і термінів здачі.
* **📤 Здача робіт:** Можливість для команд надсилати посилання на свої проекти (GitHub, Live Demo, YouTube) з описом рішень.
* **⚖️ Панель Журі:** Зручний інтерфейс для перегляду зданих робіт зі статусом "Pending" та виставлення балів за різними критеріями (Backend, Frontend, Functionality, Usability).
* **📊 Таблиця лідерів (Leaderboard):** Автоматичний підрахунок середнього балу та виведення рейтингу команд у реальному часі.

### 1. Попередні вимоги
Переконайтеся, що на вашому комп'ютері встановлені:
* [Node.js](https://nodejs.org/) (версія 18+)
